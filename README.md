One-sentence absurd invention pitch for make.fun's "One-Sentence Absurd Invention Pitch" bounty. The entry turns the most passive object in the house into its strictest gatekeeper: a doormat that job-interviews every visitor and only unlocks the door for candidates who pass the vibe check. It fixes the small daily annoyance of unwanted visitors at the door — no more opening up for someone you never wanted to let in, because the doormat already screened them.

## The entry

> A doormat that conducts a job interview for every visitor and only unlocks the door for candidates who pass the vibe check.

## Deterministic

`main.py` is deterministic: the entry is a fixed string, there is no randomness, no network access, and no time dependence. Every run writes byte-identical output to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. The program validates the entry before writing (one non-empty line, exactly one sentence, at most 220 characters) and exits with code 1 if validation fails.

## Run it

```sh
python3 main.py
```
